VNI インベントリ（ファブリック全体）

このビューは実際のCisco Nexus Dashboard（Fabric Controller）のAPI/データモデルを 再現したものではなく、エミュレータ内のNexus装置に投入されたCLI設定 （feature nv overlay / evpn / interface nve1 / address-family l2vpn evpn 等）をダッシュボード形式に投影したものです。 「VXLAN Ready」は feature nv overlay が有効・nve1が構成済み・ address-family l2vpn evpnが有効の3条件が揃っている状態を指し、 実際にBGP EVPN NLRIが交換されていることを意味しません （詳細は docs/evpn-vxlan-nexus.md 参照）。
