RESTCONF ヘルスダッシュボード ietf-interfaces経由でCisco/Catalyst装置を横断監視

更新間隔 最終更新: -
このダッシュボードは GET /api/restconf/dashboard（セッショントークン認証） 経由で取得したデータを表示している。実際のRESTCONF API本体 （/restconf/<device_id>/data/...）はHTTP Basic認証で保護されており、 ここでの表示はその集計結果。「RESTCONF READY」は装置に restconfコマンドが投入済みであることを示すだけで、 実際に外部からRESTCONF APIを叩けることの保証ではない （ip http secure-serverも別途必要。詳細は docs/restconf-catalyst.md参照）。
