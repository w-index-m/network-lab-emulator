## 2. エヴァ風の表示

- **EMERGENCY**:横一列の帯をやめ、右上と左下の角から約30°の斜めの帯(六角形の階段)で迫ってくるようにした。波が走り、一瞬消えたりもする。数個おきに「警」が入る。スマホ幅では下の両隅から V 字。
- **情・注・警の六角形**:左下に小さな六角形の尾が3つ連なり、光が走る。急ぎの度合いで速さが変わる(警 > 注・予 > 情)。

## 3. 単体版(cyber-view-standalone、自宅の Catalyst 用)

- **SNMP で流量を直接取得**:Prometheus が無くても流量が出る(`sources.snmp.traffic: true`)。IF-MIB の ifHCIn/OutOctets の差から bps を出し、ifOperStatus は LINK DOWN の検知経路 POLL に使う。2回続けて応答が無ければ「応答なし」。
- **`devices[].snmp: false`**:監視用の PC など、SNMP に応答しない装置を問い合わせ対象から外す。画面とリンクには載る。
- **古い linkDown の後始末**:trap は UDP なので linkUp を取りこぼすことがある。linkDown から 90 秒(`sources.snmp_trap.stale_after`)たっても POLL が up なら、その down を捨てる。捨てた down は、その後 SNMP が応答しなくなっても復活しない。

## 4. エミュレータの修正

- **IF-MIB**:L2 のアクセスポート(IP の無い switchport)が出るようになった。既存の ifIndex は変えない。
- **PC の ping**:`ping -c N -s SIZE` でカウンタが動き、表示も Linux 形式になった。オプション無しの ping も Linux 形式。
- **PC の ifconfig**:`ifconfig eth0 <ip> netmask <mask>` で IP が本当に設定されるようになった(以前は表示だけ)。
- **STP の復旧ログ(実バグ)**:`no shutdown` でリンクが戻るとき、相手側の `%LINK-3-UPDOWN ... up` が出ないことがあった。そのため /cyber-view の SYSLOG の根拠が down のまま残っていた。
  - 原因:リンクを up にしてから STP の `port_up` が走るまでの間に、相手の BPDU 送信がポートを黙って作り直していた。`port_up` は「もうある」と判断して抜け、ログを出さなかった。
  - 修正:shutdown で落としたポートは `port_up` だけが作り直す。リンクを消して張り直した場合は、通常どおり STP に参加する。

## 5. テストの安定化

GitHub のテストで時々落ちていたテスト2件を直した。

- **L2 ループのテスト**:別のテストが読み込み時にアプリを起動するため、全体テストの間ずっと裏の定期処理(1秒ごとのループ検知)が動いていた。それがテストより先に警報を出していた。テスト中は裏の処理を止め、検知を直接呼ぶようにした。
- **RIP の経路フィルタのシナリオ**:`network` を先に入れると RIP が動き出し、フィルタ(`distribute-list`)を入れる前の更新で対象の経路が隣に届くことがあった(実機でも 180 秒で消えるまで残る)。`distribute-list` を `network` より前に入れるようにした。
